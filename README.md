# 🀄 중국어 숫자(0~10) 손글씨 마스터 (Chinese Number Handwriting Master)

중국어 기초 숫자 **0(零)부터 10(十)**까지의 **간화자(简体字)**를 올바른 필순(획순)으로 직접 쓰고 채점받는 **손글씨 중심 인터랙티브 학습 웹 애플리케이션**입니다.

---

## ✨ 핵심 기능

1. **대형 米자 격자(米字格) 손글씨 스튜디오 (메인 화면)**
   - 화면 중앙에 큼직하고 시원한 **米자 격자 / 田자 격자** 캔버스 배치
   - 은은한 가이드 글자 오버레이 온/오프
   - 붓펜 느낌의 부드러운 드로잉 (먹물, 주홍, 남색 색상 및 3단계 붓 굵기 지원)
   - 픽셀 오버랩 알고리즘 기반 **실시간 정확도 채점 (100점 만점)** 및 별점·폭죽 피드백
   - **이전 숫자(◀) / 다음 숫자(▶)** 빠른 넘기기 지원으로 끊김 없는 손글씨 연습 흐름

2. **0부터 10까지 완전 정복 (기초 숫자 집중)**
   - 0(零), 1(一), 2(二), 3(三), 4(四), 5(五), 6(六), 7(七), 8(八), 9(九), 10(十)
   - 큰 수 단위를 배제하고 가장 중요한 0~10 기초 숫자에 집중

3. **원어민 발음 듣기 & 4성 성조 가이드**
   - Web Speech API 기반 원어민 중국어(zh-CN) 발음 재생
   - 표준 속도(0.9x) 및 초보자용 느린 발음(0.65x)
   - 성조별 톤 다이어그램 및 발음 요령 안내
   - 실생활 예시 단어(零下, 一月, 四季 등) 발음 청취

4. **중국 고유 1~10 한 손 숫자 제스처 (手势)**
   - 현지 시장이나 일상에서 사용하는 한 손 표현법 (6🤙, 7🤌, 8👉, 9☝️, 10✊)

5. **획순(笔顺) 애니메이션 & 필순 규칙**
   - 획 순서대로 빨간색으로 그려지는 인터랙티브 SVG 획순 재생 애니메이션
   - 한자 필순 5대 기본 원칙 도움말

6. **종합 진단 퀴즈 모드**
   - 발음 듣기, 독음 맞히기, 직접 손글씨 쓰기, 중국어 숫자 연산 퀴즈
   - 결과 리포트 및 오답 복습 노트

7. **로컬스토리지(LocalStorage) 진도 관리**
   - 별도 로그인 없이 브라우저에 글자별 연습 횟수, 최고 점수, 퀴즈 이력 안전 저장

---

## 🛠️ 기술 스택

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons
- **Audio / TTS**: Web Speech API (`SpeechSynthesis`)
- **Graphics & Animation**: HTML5 Canvas (DPR 레티나 스케일링), Canvas Confetti
- **Storage**: 브라우저 LocalStorage
