# 🀄 중국어 숫자 손글씨 쓰기 & 발음 마스터 (Chinese Number Handwriting & Pronunciation Master)

중국어 숫자(0~10, 백, 천, 만, 억, 량)의 **간화자(简体字)**와 **성조 병음(Pinyin)**을 올바른 필순(획순)으로 손글씨를 쓰며 익히고, **원어민 발음 청취 및 다양한 퀴즈**를 통해 학습 성취도를 스스로 점검할 수 있는 인터랙티브 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **米자 격자(米字格) 손글씨 캔버스 & 실시간 정확도 채점**
   - 전통 서예 연습용 米자 격자 및 田자 격자 지원
   - 은은한 가이드 글자 오버레이 온/오프
   - 붓펜 느낌의 스무딩 획 그리기, 먹물/주홍/남색 색상 및 굵기 선택
   - 비트맵 픽셀 오버랩 알고리즘 기반 **실시간 정확도 채점 (100점 만점)** 및 칭찬 효과

2. **표준 발음 청취 & 4성 성조 가이드**
   - Web Speech API 기반 원어민 중국어(zh-CN) 발음 재생
   - 초보자를 위한 또박또박한 보통 속도(0.9x) 및 느리게 듣기(0.65x)
   - 4개 성조(1성 음평성, 2성 양평성, 3성 상성, 4성 거성)별 발음 요령 및 시각적 색상 태그
   - 실생활 예시 단어(一月, 四季, 零下, 两个人 등) 발음 듣기 지원

3. **중국 고유 1~10 한 손 숫자 제스처 (手势)**
   - 중국 현지 시장 및 일상에서 널리 쓰이는 한 손 숫자 표현법 안내 (6🤙, 7🤌, 8👉, 9☝️, 10✊)

4. **획순(笔顺) 단계별 애니메이션 & 필순 규칙**
   - 획 순서대로 빨간색으로 그려지는 인터랙티브 SVG 획순 재생 애니메이션
   - 한자 필순 5대 기본 원칙 안내

5. **종합 퀴즈 & 학습 성취도 평가**
   - **발음 듣기 퀴즈**: 소리를 듣고 맞는 간화자 맞히기
   - **독음 & 병음 퀴즈**: 글자를 보고 알맞은 병음과 뜻 맞히기
   - **손글씨 쓰기 퀴즈**: 아라비아 숫자를 보고 직접 간화자를 써서 65점 이상 통과하기
   - **중국어 숫자 연산 퀴즈**: 중국어 수식(예: 三 + 五 = ?) 풀기
   - 퀴즈 완료 시 등급(신선, 달인, 견습생, 초보자) 부여 및 오답 복습 노트

6. **로컬스토리지(LocalStorage) 진도 관리**
   - 로그인 없이 브라우저 내에 글자별 손글씨 연습 횟수, 최고 점수, 퀴즈 이력 안전 저장

---

## 🛠️ 기술 스택

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons
- **Audio / TTS**: Web Speech API (`SpeechSynthesis`)
- **Graphics & Animation**: HTML5 Canvas (DPR 레티나 스케일링), Canvas Confetti
- **Storage**: 브라우저 LocalStorage
